Enable GM Mode
Adds a toolbar with quick session tools (Quick NPC, Session Prep, What's at Stake), and shifts terminology to TTRPG-native ("Realm" instead of "Nation", "Timeline" instead of "Chronicle"). Designed for tabletop Game Masters preparing for play. Requires a Copilot API key for the toolbar buttons to work.
Copilot
Provider
OpenRouter routes to any cloud model. Ollama runs a model locally on your machine — no API key, no data sent to any server.
OpenRouter API key
Stored locally only — never sent anywhere except OpenRouter. Get one free at openrouter.ai/keys
Model
Sonnet is the recommended balance of cost and reasoning. Haiku for fast/cheap; Opus for hard problems.
Ollama base URL
Default is http://localhost:11434. Make sure Ollama is running and CORS is open (OLLAMA_ORIGINS=*).
Ollama model
Must be pulled locally first: ollama pull llama3.1. Recommended: llama3.1, mistral, or gemma3.
